# graders：deaify-wechat-article 验收标准

改写后的成稿按以下条目逐条验收。任何一条不过 = 测试失败。

## 1. 事实与信息零丢失（保真）

- [ ] 「300 万上系统最后闲置」案例保留（具体金额与结果是作者材料）
- [ ] 「员工不会用也不愿意用」的原因分析保留
- [ ] 培训/数字素养的建议保留
- [ ] 「道阻且长，行则将至」类引用如被改写，需保留其时间跨度的含义
- [ ] 无新增事实（不得补造案例、数据、人名）

## 2. slop 清除（对照 SKILL.md 模式）

- [ ] 三段式「首先/其次/最后 + 加粗开头」结构被打散或重排（#6/#19）
- [ ] 「不仅是……更是……」「不是……而是……」的空泛对比清除或按 #1 判定路径处理（真实的对比信息保留）
- [ ] 「在这个数字化的时代」时代开头删除（#4）
- [ ] 「总而言之……共创美好未来」空转收尾删除（#2/#3）
- [ ] 每段加粗句式不再全篇套用（#19）
- [ ] 「任重而道远」格言堆叠不再连用（#3，保留一处真实使用的可以）

## 3. venue 契合（references/venues/wechat-article.md）

- [ ] 短段落节奏保留（公众号阅读习惯）
- [ ] 老周的第一人称视角保留（他是亲历者，不是旁观叙述）
- [ ] 面向中小企业主的表达（不端学术腔）
- [ ] 结尾无套模板升华（有真实收束内容可以）

## 4. 反过度执法（references/zh-signals.md）

- [ ] 改写中出现的正常「不是……而是……」（承载真实对比）未被误删
- [ ] 必要的三项并列（三个独立建议）未被强行砍成两项
- [ ] 无过度打磨痕迹：保留朴素句子，不把全文磨成同质光滑腔
- [ ] 「道阻且长，行则将至」若保留且承担真实收束，不算 slop
